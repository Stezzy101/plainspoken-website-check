# Plainspoken Free Website Check

This version is completely free to run locally.

## What it does
- Fetches a public homepage
- Checks headings, CTA wording, trust signals, contact info, service structure and word count
- Produces a clarity score
- Shows strengths, issues and a recommended homepage structure
- Uses no OpenAI API and needs no API key

## How to run

1. Unzip the folder.
2. Open the folder in VS Code.
3. Open Terminal in VS Code.
4. Run:

   npm install

5. Then run:

   npm start

6. Open this in your browser:

   http://localhost:3000

Important: do not use VS Code Live Server / port 5500 for this version.

## Notes
Some websites block automated access or require login, so those cannot be checked by this simple prototype.
